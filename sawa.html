Category: Community Platform / Social App

Timeline: 5–6 weeks

Tools Used: Figma, Adobe Photoshop

Overview

A community app for discovering activities, meeting like-minded people, and joining real-world events.

I designed the mobile experience and admin dashboard.

Jump to designs ↓

The Problem

Finding activities and building meaningful connections can be difficult in a fast-paced city.

  • Activity listings are scattered
  • Users need safer ways to meet
  • Online connections don’t always lead to real events

The Goal

Help attendees and hosts discover events, connect through shared interests, and interact safely.

Target Users

Young professionals, expats, and anyone seeking meaningful connections.

Key Product Challenges

Balance relevant discovery, user safety, privacy, and a feature-rich product in a simple experience.

My Approach

Personalized discovery and clear actions help users join, book, or host events. Temporary interactions support privacy and safety.

User Flow

Onboarding → Interest Selection → Personalized Feed → Event Details → Join Event → Temporary Chat → Attend → Feedback

Relevant events are easy to find, and chat opens after joining.

The Solution

A single platform for:

  • Discovering, joining, and hosting events
  • Safe interaction and moderation

Key Feature Highlight

Temporary event chat

Chat unlocks after joining an event and closes when it ends, supporting coordination while protecting privacy.

Design Process

Design System
Created a dark theme with reusable components and consistent type and spacing.

Wireframes
Simplified key flows and prioritized Join, Book, and Host actions.

High-Fidelity UI
Used scannable cards, strong contrast, and clear calls to action.

Admin Dashboard
Designed tools for moderation, event approvals, reports, payments, and analytics.

Key Design Decisions

✔ Card-based feed for quick scanning

✔ Interest-based discovery for relevant events

✔ Temporary chat for safer interaction

Challenges

Keep event, chat, and hosting features clear while balancing safety with engagement.

Expected Impact

  • Make event discovery more relevant
  • Encourage participation and safer interactions

Key Learnings

  • Clear flows make participation easier
  • Trust and safety are essential
  • Simplicity matters more than extra features

Final Result

  • Design for real-world behavior
  • Balance user needs, safety, and business goals
