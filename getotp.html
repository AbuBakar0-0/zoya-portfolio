01Overview

GetOTP. One job: get a working code before it expires.

People often need a phone number to sign up for a service but don't want to share their own. GetOTP sells short-term virtual numbers. You pick a service and a country, get a number, and the SMS code appears in the app.

The mobile app runs on coins, which you can buy in packs or earn through small tasks. The web side has a landing page that explains the service and a portal where you top up a balance, buy numbers and track active codes.

02The challenge

Three things the design had to get right.

Each one shaped a specific part of the interface you'll see further down.

Time

Codes expire

A code is only useful for a few minutes. The number, the code and the time left need to be readable at a glance and copyable in one tap.

Trust

People pay up front

Users pay before anything arrives. The price, the country and what happens if no code comes need to be clear before payment.

Consistency

Two surfaces, one model

Mobile uses coins and the web uses a wallet balance. Both had to follow the same order: service, country, number, code.

Approach

Built around “My Numbers”

A home screen centred on active numbers, a three-step purchase flow on both platforms, and clear states for expired codes and missing SMS.

4.1The OTP card

A code you can read and copy at a glance.

The number card carries the whole job. When a code arrives it takes over the card. When the timer runs out, the card switches to a recovery state instead of disappearing.

  • Live. Number, service and the code in large blue digits, each with its own copy button.
  • Countdown. Time left sits in a warm red row under the code, so urgency is visible without an alert.
  • Expired. The card shows when the last code expired and offers a single “Generate New OTP” action.
Code receivedCode expired
4.2Coins

Buy coins or earn them, in light and dark mode.

The More Coins screen splits into two groups: free coins at the top, paid packs below. Bigger packs show their bonus as a green pill so the value is visible without any maths.

  • Earn for free. Daily gift, share the app and rate us. Each is worth 5 coins, and the daily gift shows a cooldown timer once claimed.
  • Buy more. Packs list the coin count, the bonus and the price in rupees.
  • Both themes. The same layout ships in light and dark, with the gold coin art carrying across both.
LightDark
4.3Guidance

Help in the place people get stuck.

Getting a number is easy. The tricky part is using it in another app. The guide walks through that hand-off and answers the three questions most likely to come up.

  • Four steps. Open WhatsApp, enter the number, request the code, come back to GetOTP.
  • Copy inline. The purchased number sits inside step 2 with its own copy button.
  • Need help? Didn't receive a code, entered the wrong number, timer expired.

6.1Dashboard

Balance, usage and live codes on one screen.

The dashboard mirrors the mobile home screen: money at the top, one clear call to action, and active numbers below.

  • Two summary cards. Account balance and total numbers used, each with a short trend line.
  • Need a Number? The main action gets its own banner instead of hiding in the sidebar.
  • Active and History tabs. Each active number shows its service, country, OTP and expiry time.

08Decisions & next steps

What I'd stand behind, and what I'd measure.

The product doesn't have live data yet, so this section lists the signals I'd track after launch instead of results.

Key decisions

  1. 01One card per numberThe number, code, timer and recovery action all live on the same card, so there is no separate code screen.
  2. 02Same order on both platformsService, then country, then payment, so people who use both don't have to relearn anything.
  3. 03Refund terms before paymentThe “didn't receive your code?” note sits beside the payment form, not in an FAQ.
  4. 04Free coins as a way inSmall tasks let new users get coins before they spend any money.

What I'd measure next

  • →Time to codeFrom tapping Get New Number to the OTP showing on the card.
  • →Codes received before expiryHow often the timer runs out first, and how often “Generate New OTP” fixes it.
  • →Free-coin claimsWhich of the three tasks people complete, and whether they go on to buy a pack.
  • →Pack mixWhich pack sizes sell, to check whether the bonus tiers are working.

Results will be added here once there is real usage data.
